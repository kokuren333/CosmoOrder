# 症例の情報を統合する

ここでは、同じ症例について「記録された事実」と「そこから考えられること」を分けます。架空の成人Aさんは、2日間の水様便が続き、食事と飲水が減っています。本人は、尿量が普段より少ないと話しています。臥位から立位に変わると脈拍が上がりましたが、血圧に大きな変化はありません。血清ナトリウム濃度は基準範囲内でした。

| 記録された情報 | そこから考えられること | まだ決められないこと |
| --- | --- | --- |
| 水様便が続き、飲水が減った | 水と電解質の出入りが負の方向に傾いた可能性 | 実際の喪失量、便の組成 |
| 本人が尿量の減少を申告した | 腎臓への循環や摂取状況を考える手掛かり | 客観的な尿量、腎機能、普段との比較 |
| 起立時に脈拍が増えた | 姿勢変化に対する循環反応を確認する必要 | 体液量減少だけが原因かどうか |
| 血圧は大きく変わらず、ナトリウム濃度は基準範囲内 | この二つの所見は今回の情報の一部 | 循環血液量や総水分量が保たれているか |

摂取低下と便からの喪失に、尿量の変化と起立時の所見が重なっています。これらは**細胞外液量が低下している可能性**と整合します。ただし、原因や程度をこの記録だけで確定することはできません。血圧や血清ナトリウム濃度が一見保たれていることも、体液量の評価を終わらせる根拠にはなりません。

## まとめるときの順序

1. **事実を列挙する。** 摂取、喪失、症状、診察、測定値を分ける。
2. **体液区分を意識する。** 総水分量、細胞外液、血漿量を混同しない。
3. **変化の時間軸をそろえる。** いつから変化し、どの条件で測ったかを確認する。
4. **推論と不確実性を併記する。** 「整合する」と「確定した」を使い分ける。

このように書けば、所見を見落とさず、未測定の量や別の原因を事実のように補うことも避けられます。実際の患者評価や対応は、担当チームの診察と施設の手順に基づいて行われます。
